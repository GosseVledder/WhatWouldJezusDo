📖 Stap-voor-stap handleiding (For Dummies)
  1. Open console.cloud.google.com met je Google-account.
  2. Kies bovenin een project (of maak een nieuw project WWJD aan).
  3. Open Fact Check Tools API en tik op Enable / Inschakelen.
  4. Ga naar Credentials → + Create Credentials → API key.
  5. Kopieer de AIzaSy... sleutel en plak hem hierboven.
